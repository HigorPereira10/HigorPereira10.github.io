Ecovision

Meu TCC, desenvolvido em equipe: um sistema de IoT e visão computacional para detectar cedo pragas e anomalias em estufas de tomate. A cada duas horas, um Raspberry Pi fotografa as folhas e lê os sensores do ambiente. Uma API na nuvem roda o modelo de IA e o produtor acompanha tudo e recebe alertas por um app no celular.

  1. Raspberry Pi + câmerafotos e sensores
  2. API no RailwayFastAPI · TFLite
  3. SupabasePostgres + Storage
  4. AppExpo · React Native
Borda
Raspberry Pi Zero 2 W, Camera Module 3 com autofoco, sensores DHT22 e de umidade do solo, fila offline para quando a rede cai.
IA
Modelo treinado com TensorFlow/Keras no Google Colab e convertido para TensorFlow Lite.
Nuvem
API em FastAPI no Railway, inferência em memória e deploy automático com GitHub Actions.
Dados
Supabase: Postgres para leituras e diagnósticos, Storage para as imagens.
App
Expo e React Native, login com JWT e notificações para o produtor.
